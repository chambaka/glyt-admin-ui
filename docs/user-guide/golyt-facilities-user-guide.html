Before you start

  • Open the ops console (glyt-admin-ui) and sign in as ADMIN.
  • READONLY users can view the lists but cannot add, edit, or delete.
  • Facility codes such as KIA and ZNZ are referenced by staff, bags, and storage — treat them as durable identifiers.
Concepts

1. What Facilities covers

Locations Storage slots Corridor ops

The Facilities page has two boards: Facilities (physical locations on the corridor) and Storage slots (shelf / bin codes used when bags are stored, typically at ZNZ).

LocationKIA, ZNZ, desk…
Staff / bagsBind to location code
Storage slotShelf under a facility
OccupiedShows linked bag
  • Code — short stable key (e.g. KIA, ZNZ). Set at create; cannot change later.
  • Type — AIRPORT, HUB, DESK, or OTHER.
  • Active — inactive facilities stay in history but should not be used for new work.
  • Storage slot — belongs to one facility; may be occupied by a bag.
Prefer deactivate over delete when a code is already in live operations. Deletes only succeed when nothing still references the facility or slot.
Ops console

2. Facilities list & CRUD

ADMIN only for write Add / Edit / Delete Refresh

Open Facilities in the left rail. The top table lists location code, name, type, and active status. Use Refresh to reload both facilities and storage from the API.

Add a facility

  1. Choose Add facility.
  2. Enter a unique Code, display Name, and Type.
  3. Leave Active checked unless you are pre-creating a dormant site.
  4. Confirm with Create facility. A success notice confirms the save.

Edit a facility

  • Use the pencil icon on a row.
  • You can change name, type, and active flag.
  • Code is locked after create (staff, storage, and bags already reference it).

Delete a facility

  • Use the trash icon. Confirm in the danger dialog.
  • Delete only works if no staff, storage slots, or bags still reference the facility.
  • If blocked, an error notice explains why — clean up references or deactivate instead.

3. Storage slots

Usually ZNZ Occupied + bag code Add slot

Storage slots are shelf/bin codes under a facility. Officers assign bags into free slots when receiving into destination storage (phone ops app). The console shows occupancy and the linked bag.

Add a slot

  1. Choose Add slot on the Storage slots card (ADMIN).
  2. Enter a unique slot Code (e.g. A-01).
  3. Pick the parent Facility (KIA / ZNZ / other configured codes).
  4. Set Active and save with Create slot.

Edit a slot

  • Pencil icon — change facility assignment and active flag.
  • Slot code is locked after create.

Delete a slot

  • Trash is disabled while the slot is occupied.
  • If you try while occupied, a warning notice appears: free the bag first.
  • Empty slots can be deleted after the confirm dialog.
Occupied slots show Yes and the bag code (e.g. BAG-0038). Do not delete or deactivate a slot that still holds a bag until custody moves on.
Integrity

4. Integrity & delete rules

Referential safety Confirm dialogs Notices

GoLyt blocks deletes that would break operational data. Confirm and error dialogs keep the desk from removing live references by accident.

Facility delete blocked when

  • Staff users are still assigned to that location code.
  • Storage slots still belong to that facility.
  • Bags still reference that facility / location.

Storage delete blocked when

  • The slot is occupied (a bag is shelved there).

Safer alternatives

  • Uncheck Active to retire a facility or slot without losing history.
  • Move or release bags before deleting storage.
  • Reassign staff location before removing a facility code.
Never force-delete through the database. Use the console so referential checks and audit-friendly API paths run.
Reference

5. Roles, tips & related menus

Who can do what

  • ADMIN — add, edit, delete facilities and storage slots.
  • READONLY — view both tables; no write actions.
  • KIA / ZNZ officers — use locations and slots from the phone app during intake, receive, and shelving; they do not manage the Facilities board.

Field quick reference

  • Facility types: AIRPORT · HUB · DESK · OTHER
  • Facility code immutable after create
  • Storage code immutable after create
  • Occupied → linked bag code shown

Quick tips

  • Create storage slots before peak ZNZ receiving days.
  • Use clear slot codes (row-shelf) so officers can find bags quickly.
  • Deactivate unused slots instead of deleting if you may reuse them.
  • Keep KIA and ZNZ active — they anchor the pilot corridor.
