Concepts

1. What a manifest is

Airline handoff Sealed custody JRO → ZNZ

A manifest is the flight-level list of sealed bags moving from Kilimanjaro (KIA / JRO) toward Zanzibar under airline custody. It is not GPS tracking — it is a signed custody record.

DRAFTBuild bag list
FINALISEDLocked for airline
HANDED_OVERWith airline
Follow-upFlag missing
  • Manifest numbers look like MF-JRO-ZNZ-#####.
  • Default route is JRO-ZNZ.
  • Each bag can sit on only one manifest.
  • Printable PDF is available for desk handoff and archive.
Only draft manifests can be edited (add / remove bags). Finalise locks the list before airline handover.

2. Manifests in the ops console

ADMIN / READONLY List PDF download

Open Manifests in the left rail. The page lists recent manifests with airline, flight, bag count, and status.

  • Review corridor handoffs without opening the phone app.
  • Choose PDF on a row to download the printable manifest for that flight.
  • Use the PDF at the KIA desk, for airline counters, or for audit archives.

Creating and editing manifests is done in the GoLyt phone ops app (KIA officers). The console focuses on visibility and printable handoff documents.

3. Manifest lifecycle on the phone app

KIA_OFFICER ADMIN Create → Finalise → Handover

Create a draft

  1. Open Menu → Manifests.
  2. Start a new manifest and enter airline, flight number, date, and optional notes.
  3. GoLyt assigns a number such as MF-JRO-ZNZ-00042.

Add sealed bags

  1. Open the draft and select eligible bags (status SEALED with a seal number).
  2. Add them to the manifest. Remove a bag only while status is still DRAFT.
  3. A bag already on another manifest cannot be added again.

Finalise

  • When the bag list is complete, Finalise the manifest.
  • Status becomes FINALISED. Bag list changes are no longer allowed.

Airline handover

  • After finalise, record Handover when bags leave with the airline.
  • Status becomes HANDED_OVER (airline custody toward Zanzibar).
Download the PDF from the ops console (or generate from the API) so the airline desk has a paper copy matching the sealed bag set.
Phone app · ZNZ

4. After airline handover

ZNZ receiving Missing bags

Zanzibar officers receive bags from airline custody into storage. If bags that were on a handed-over manifest do not arrive, officers can flag them as missing.

  • Use the ZNZ receiving / airline-custody views in the phone app.
  • Flag missing is available after handover — not on drafts.
  • Flagging opens (or refreshes) a NOT_RECEIVED exception for follow-up on the Exceptions board.

Status checklist

  • DRAFT — editable bag list
  • FINALISED — locked; ready for airline
  • HANDED_OVER — with airline; ZNZ can flag missing

5. Roles, rules & tips

Who can do what

  • KIA_OFFICER / ADMIN — create, add/remove bags (draft), finalise, handover.
  • ZNZ_OFFICER — receive after airline custody; flag missing on handed-over manifests.
  • ADMIN / READONLY — view list and download PDF in the ops console.

Integrity rules

  • Only sealed bags with a seal number can join a manifest.
  • A bag cannot be on two manifests.
  • Only drafts can be edited; only finalised manifests can be handed over.
  • Missing flags require handover first.

Quick tips

  • Seal every bag before building the flight list.
  • Finalise only when the physical set matches the screen.
  • Print the PDF before airline counters close.
  • Watch Exceptions for NOT_RECEIVED after handover.
