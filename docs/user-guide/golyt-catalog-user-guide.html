Before you start

  • Open the ops console and sign in as ADMIN for create / price / enable actions.
  • READONLY and officers can view the list but cannot change offerings.
  • Prices are stored in minor units (cents / cents-equivalent) — see the conversion table in section 4.

1. What Catalog covers

Services Pricing Quotes

The Catalog page (labelled Service catalog) lists sellable services and their active prices. Customer quotes and bookings draw from active services only.

PriceMinor units + currency
UnitPer bag / booking / flat
ActiveShown in quotes
  • Code — short stable key (e.g. DOOR_TO_DESK, OVERWEIGHT).
  • Name / description — what desks and customers see.
  • Sort order — lower numbers appear first in lists.
  • Unit — PER_BAG, PER_BOOKING, or FLAT.
Disable a service instead of deleting it when you need to retire an offering without losing history.

2. Reading the service list

ADMIN write Refresh Active / Inactive

Open Catalog in the left rail. The table shows code, name (with description), formatted price, unit, sort order, and status.

  • Use Refresh to reload services from the API.
  • Price is shown as currency + major units (e.g. TZS 50,000 from minor amount 5000000).
  • ADMIN rows expose Disable / Enable and Set price.

3. Create a service

ADMIN only New service form

At the bottom of the Catalog page, ADMIN users see the New service form.

  1. Enter a unique Code (use UPPER_SNAKE for consistency).
  2. Enter display Name and optional Description.
  3. Set Amount (minor units), Currency (usually TZS), and Unit.
  4. Set Sort order (e.g. 10, 20, 30) so primary products appear first.
  5. Choose Create service. A success notice confirms the save.
Amount is not entered as whole shillings. TZS 50,000.00 → 5000000 minor units (multiply by 100).

Typical pilot offerings

  • DOOR_TO_DESK — corridor custody KIA → ZNZ
  • OVERWEIGHT — extra handling above threshold

4. Set price & enable/disable

Set price Enable / Disable Confirm dialogs

Update price

  1. Choose Set price on a service row.
  2. The Update price form appears with amount (minor units), currency, and unit.
  3. Save with Save price, or Cancel to discard.

Enable / disable

  • Disable — service stays in Catalog but is hidden from new quotes. Confirm in the danger dialog.
  • Enable — brings the service back for selling. Confirm in the warning dialog.
  • Inactive services remain visible to ADMIN for audit and re-pricing.
Changing price does not rewrite historical bookings or payments — it affects new quotes going forward.

5. Roles, tips & related menus

Who can do what

  • ADMIN — create services, set price, enable/disable.
  • READONLY / officers — view the catalog list only.

Field quick reference

  • Units: PER_BAG · PER_BOOKING · FLAT
  • Currency default: TZS
  • Amount: integer minor units (×100 for TZS)
  • Sort: lower = earlier in lists

Quick tips

  • Keep door-to-desk as the primary sorted service.
  • Double-check minor units before Save price.
  • Disable seasonal add-ons instead of inventing one-off codes.
  • Refresh after another admin changes prices.
