# GoLyt ops console

Vue operations console for **operations lead** and **read-only** management.

KIA / Zanzibar officers use the Flutter ops app (`glyt-app`), not this console.

## Features

- Dashboard, bags search, bookings, manifests (PDF), exceptions, filtered CSV reports
- ADMIN user create + enable/disable

## Run

```bash
npm install
npm run dev
```

Opens at `http://localhost:5180` (proxies `/api` to `http://localhost:8080`).
